# pptx-typst

**Convert between PowerPoint and Typst while preserving the original presentation design.**

`pptx-typst` is an experimental bidirectional converter for Microsoft PowerPoint (`.pptx`) and Typst presentations.

The project focuses on preserving slide layouts, object positioning, images, transparency, colors, shapes, and visual hierarchy while keeping text editable and reusing original image assets.

Unlike pixel-perfect rendering approaches, `pptx-typst` prioritizes design fidelity and practical editability over exact font metrics, line wrapping, or chart appearance.

**Project status:** Proof of Concept (PoC). Both conversion directions are demonstrated for a supported subset of presentation constructs. Not yet intended for production use.
