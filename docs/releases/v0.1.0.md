# pptx-typst 0.1.0

`pptx-typst` is a bidirectional tool for converting PowerPoint presentations into editable Typst projects and exporting a supported static Typst subset to editable PowerPoint.

The Typst project also works as a file-based presentation IR for AI agents and automation: edit supported source and assets, then compile and export without driving an open PowerPoint session for each change. See the [agentic workflow guide](../agentic-presentation-workflow.md).

Version 0.1.0 is the first public product release. It supports common slide text, images, shapes, tables, transparency, reusable masters and layouts, and native title/body placeholders within the documented subset. Conversion reports identify unsupported objects and visual or editability fallbacks.

## Install

```console
python -m pip install pptx-typst==0.1.0
```

Python 3.10–3.13 is supported. Install the [Typst CLI](https://typst.app/) separately to compile Typst projects and render PDF previews.

## Convert and edit

```console
pptx-to-typst presentation.pptx --output presentation-typst
typst compile presentation-typst/main.typ presentation.pdf
typst-to-pptx presentation-typst/main.typ --output presentation-roundtrip.pptx
```

Or create a new supported Typst project:

```console
pptx-typst init my-deck
typst compile my-deck/main.typ my-deck/preview.pdf
typst-to-pptx my-deck/main.typ --output my-deck.pptx
```

The Python package provides these commands: `pptx-typst`, `pptx-to-typst`, `typst-to-pptx`, `pptx-typst-validate`, and `pptx-typst-fonts`. The Typst CLI is an external dependency. EMF/WMF rendering uses Windows GDI+ through the packaged PowerShell helper or Inkscape on systems where it is installed. Some SVG operations require native Cairo libraries.

## Supported scope and known limitations

- The reverse converter recognizes the documented static Typst subset; it does not evaluate arbitrary Typst programs or user-defined macros.
- Common text, shapes, images, tables, master/layout relationships, and supported title/body placeholders remain editable. Merged tables and many complex effects are unsupported or approximated.
- Native PowerPoint charts, animations, and transitions are not supported.
- SmartArt and some complex graphics may be represented as static vector artwork; their internal text and elements are not independently editable.
- Some media formats require platform-specific rendering utilities. If a compatible converter is unavailable, the conversion report records the limitation.
- Font substitution and different layout engines can change line wrapping and text placement. Check the font report and visually inspect rendered output.

Review `conversion_report.json` and inspect important slides before relying on converted output.
