# v0.1.0 experimental alpha

`pptx-typst` converts supported PowerPoint presentations into editable Typst projects and converts a documented static Typst subset back into editable PowerPoint.

This experimental alpha preserves common slide text, images, shapes, tables, transparency, and reusable master/layout structure. EMF/WMF may use rendering derivatives while original media stays in project assets. When an embedded OLE object includes a cached preview picture, the forward converter can preserve that preview; its underlying spreadsheet or chart data does not become editable in Typst. `conversion_report.json` identifies unsupported objects, visual fallbacks, and placeholder layering risks.

Install from the wheel or source archive attached to a GitHub release when one is published. During preparation, the artifacts were built locally and tested in fresh Python 3.12 and 3.10 environments. PyPI publication and the public GitHub release remain pending authorization.

Typical workflow:

```console
python -m pip install pptx_typst-0.1.0-py3-none-any.whl
pptx-to-typst presentation.pptx --output presentation-typst
typst compile presentation-typst/main.typ presentation.pdf
```

To start a Typst deck, use `pptx-typst init my-deck`. Edit its `main.typ`, compile it with the Typst CLI, and use `typst-to-pptx` for the supported reverse-conversion subset.

PowerPoint design preservation is the goal; arbitrary PowerPoint features, arbitrary Typst evaluation, exact font layout, native charts, all SmartArt editability, animation, and transitions are outside this alpha's support. Read each conversion report and inspect slides before relying on output. See the [README](../../README.md), [independent validation](../independent-validation.md), [unsupported-object audit](../unsupported-object-audit.md), and [stabilization report](../alpha-stabilization-report.md) for the tested scope and limitations.
