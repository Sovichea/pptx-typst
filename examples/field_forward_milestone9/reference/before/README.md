# FIELD / FORWARD (alignment-corrected)

Eight-slide 16:9 presentation about connected agriculture. All subject matter is illustrative, with no claimed measurements, clients, or partnerships.

The editable design master is `main.typ`. Import `pptx-typst.typ` from the accompanying project. The PPTX was generated by the actual `pptx-typst` static reverse converter.

This version corrects manual alignment of network diagram labels and numbered step badges by using `PptxTextFrame` with `anchor: "center"` and `default-align: "center"`. Card text spacing was also improved.

## Build

```sh
typst compile main.typ preview.pdf
typst-to-pptx main.typ --output field-forward-corrected.pptx
```

The Typst compiler used for verification was Typsastra enhanced Typst 0.15.1 compatible. This is an editable PPTX: 102 text boxes and 127 native shape objects, with no flattened slides. Review your fonts and visual details in your own presentation viewer before presenting.

See `QA.md` for validation results and known renderer limitations.
