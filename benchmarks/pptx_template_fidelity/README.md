# PowerPoint template fidelity benchmark

This benchmark evaluates 29 font-normalized PowerPoint templates with the repository text-fidelity benchmark methodology. Inputs were user-provided copies; the originals were not modified. The tracked manifest records hashes for the normalized inputs and source originals. The local source directory is intentionally not recorded in the repository.

The normalized PPTX files are not stored in the repository. To reproduce the run on the same PC, use the font-adjusted copies at:

```powershell
python tools/run_text_fidelity_benchmark.py `
  --manifest benchmarks/pptx_template_fidelity/manifest.json `
  --input-dir "PATH_TO_FONT_ADJUSTED_PPTX_FILES" `
  --output-dir benchmarks/pptx_template_fidelity
```

The benchmark exports each PPTX through local Microsoft PowerPoint, converts it with the installed `pptx-typst`, compiles with Typst, then reports layout fidelity, font-supported text fidelity, full-slide fidelity, visible-word recall, and structural diagnostics separately. Comparison sheets select up to three font-supported slides with the lowest text-fidelity scores for each deck. This is local-renderer evidence, not a cross-platform guarantee.

## Results

The run completed **29/29** conversions and renders with **291/291** page pairs verified. Mean per-deck scores were **88.7% layout fidelity**, **44.1% text fidelity**, and **66.4% full-slide fidelity**. Weighted visible-word recall was **92.0%**. All 291 text-bearing slides had fonts available to Typst. These are diagnostic scores from the local Windows 11 / PowerPoint 16 / Typst 0.15.1 environment, not a claim of pixel equivalence.

See [summary.md](summary.md) for score definitions and caveats, [results.csv](results.csv) for per-deck metrics, [slide_diagnostics.jsonl](slide_diagnostics.jsonl) for per-slide structural and text matches, and [visual_comparisons/index.md](visual_comparisons/index.md) for low-text-fidelity comparison sheets. The run environment is recorded in [environment.json](environment.json).

The final font normalization was checked against PowerPoint PDF font lists. For Bahnschrift, Nunito Sans, and Source Sans Pro, PowerPoint rendered the earlier mapped target as Calibri, so the adjusted inputs explicitly use Calibri for those mappings. Geometry and artwork were not changed. Two quote frames received soft line breaks to retain their source visual wraps.

Source font availability can still vary by PC. `manifest.json` identifies the exact normalized and original PPTX files by SHA-256. Results and comparison images are generated by the benchmark command above.
